Finish connecting

  1. Click in your browser's address bar and copy this page's entire address (it starts with https://swsmanager.com/oauth/callback/).
  2. Go back to the SWS Manager connect window on your computer.
  3. Paste the address there and press Enter.
  4. Then close this tab.

The address contains a one-time code that expires within minutes and works only once. Don't share it, email it, or paste it anywhere other than the SWS Manager connect window.

This page does not run any scripts, and nothing on this page is stored or sent anywhere by this website. SWS Manager's QuickBooks access is read-only.

Didn't mean to be here?

You can simply close this tab; nothing is connected until the address is pasted into SWS Manager. To disconnect SWS Manager later, see Disconnecting QuickBooks Online. Questions: info@studswsuds.com.
